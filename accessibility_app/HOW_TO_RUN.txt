# ElevenLabs and Google Gemini for Accessibility

This project connects your algorithmic trading results to Google Gemini and ElevenLabs for text-to-speech accessibility.

## File Structure
- `frontend/` : All the UI, HTML, CSS, and JS.
- `backend.py` : The separate backend server that securely communicates with the APIs.
- `run.bat` : The script to launch everything.

## How to Run

1. Open this `accessibility_app` folder.
2. Double-click the file named **`run.bat`**.

That's it! Your browser will open to `http://localhost:8000`.
